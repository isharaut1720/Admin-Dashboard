# 🚀 Admin Analytics Dashboard (React + Vite)

A modern, responsive Admin Dashboard built using React and Vite, designed for data visualization and management.

## 📌 Features
📊 Interactive charts using Recharts
🔄 Dynamic data handling with Axios
🧭 Multi-page navigation (React Router)
🎨 Clean and responsive UI
⚡ Fast performance with Vite
🧩 Modular component-based architecture

## 🛠️ Tech Stack
React 19
Vite
React Router DOM
Recharts
Axios
React Icons

## 📷 Live Demo
👉 https://admin-dashboard-isha2026.netlify.app/

## 📦 Installation
git clone https://github.com/isharaut1720/Admin-Dashboard.git
cd Admin-Dashboard
npm install
npm run dev
🏗️ Build for Production
npm run build

## 📊 Use Case
This dashboard can be used for:
Business analytics monitoring
Admin panels for web apps
Sales / revenue tracking
User data management
